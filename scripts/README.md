# Scripts

Utility scripts for testing, setup, and maintenance.

## Test Scripts

- `test_after_fixes.sh` - Run tests after applying fixes
- `test_api_endpoints.sh` - Test API endpoints
- `test_api_with_auth.sh` - Test API with authentication
- `test_backend_api.sh` - Backend API testing script
- `test_schema_fixes.sh` - Test schema fixes
- `test_schema_fixes_comprehensive.sh` - Comprehensive schema fix tests
- `test-render-deployment.sh` - Test Render deployment

## Utility Scripts

- `check_backend_status.sh` - Check backend server status
- `generate_sample_data.js` - Generate sample data for testing

## Usage

Most scripts are bash scripts. On Windows, use Git Bash or WSL to run them.

```bash
# Example: Run API tests
./scripts/test_api_endpoints.sh

# Example: Check backend status
./scripts/check_backend_status.sh
```
